# Redactwizard: Professionelle KI-Dokumentenanonymisierung (Offline)

[![Website](https://img.shields.io/badge/Website-redactwizard.de-blue)](https://redactwizard.de)
[![English](https://img.shields.io/badge/Global-redactwizard.com-green)](https://redactwizard.com)

**Redactwizard** ist eine leistungsstarke Desktop-Anwendung für Windows, die speziell für das automatische Schwärzen und Anonymisieren von PDF-Dokumenten, Word-Dateien (DOCX) und Bildern entwickelt wurde. 

Der entscheidende Vorteil: Die gesamte Verarbeitung erfolgt **100% lokal auf Ihrem System**. Es findet kein Datentransfer in die Cloud statt, was maximale DSGVO-Konformität garantiert.

---

## 🚀 Hauptmerkmale

- **KI-gestützte Erkennung:** Erkennt automatisch über 35 Entitätstypen (PII) wie Namen, Adressen, IBANs, E-Mails und mehr.
- **Vollständige Offline-Verarbeitung:** Keine Internetverbindung zur Anonymisierung erforderlich. Ideal für sensible Behörden- oder Kanzleidaten.
- **Sichere PDF-Neugenerierung:** Statt Texte nur zu überlagern, erzeugt Redactwizard eine komplett neue PDF ohne versteckte Metadaten oder Ebenen.
- **Stapelverarbeitung (Batch):** Anonymisieren Sie hunderte Dokumente gleichzeitig in Sekunden.
- **Multilingual:** Unterstützung für alle wichtigen europäischen Sprachen durch spezialisierte RoBERTa-KI-Modelle.

## 🛠 Unterstützte Formate
- **Dokumente:** PDF, DOCX, TXT, RTF, LOG, CSV, XML
- **Bilder (Max Edition):** JPG, PNG, WEBP, TIFF, BMP (inkl. OCR-Unterstützung)

## 📥 Download & Installation
Die Software kann als Sofort-Download installiert werden. Es stehen zwei Editionen zur Verfügung:
1. **Download Edition:** Kompakter Installer (ca. 18MB), lädt KI-Modelle beim ersten Start.
2. **Air-Gapped Edition:** Enthält alle KI-Komponenten direkt im Installer für isolierte Umgebungen.
